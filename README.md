# cosc219-site
This site is for my cosc219 class. It features things about me and my interests like mushrooms, flowers, and videogames.
Find the full page here: https://ddawg9.github.io/cosc219-site/index
I found working with tables to be challenging.
I used the help of stack overflow and W3Schools to give me a better understanding of the html and css. The use of AI was avoided.
I styled my website the way I did because of my preference for times new roman and I thought the color would suit it.
Layout note: I chose 38rem, 42rem, and 58rem. I looked at the rem for standard screen size then adjusted it to my own computer afterwards.
Flexbox was used for the navigation bar because it needs to be in a line or a stack and it looks nicer. I used a grid for my project and about page because it works better for aranging rows and columns together.
